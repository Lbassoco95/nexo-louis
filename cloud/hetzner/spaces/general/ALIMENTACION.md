# 🍽️ Control de Alimentación — Polo

Bitácora de comidas. Louis anota aquí automáticamente cuando Polo dice qué comió
(p.ej. "desayuné fruta", "comí pollo con verduras", "cené ensalada", "merendé yogurt").

Formato de cada línea: `- [YYYY-MM-DD HH:MM] 🍽️ <verbo>: <comida>`

Esto es el carril SEPARADO de SALUD.md (que guarda citas médicas / medicamentos).
Aquí solo va alimentación, para poder llevar un control limpio y reviewable.
